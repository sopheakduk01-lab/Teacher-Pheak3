# សំណើគម្រោង៖ ប្រព័ន្ធគ្រប់គ្រងការខ្ចីសៀវភៅ (Book Borrowing Tracker)

## គោលបំណង
បង្កើតប្រព័ន្ធងាយស្រួលសម្រាប់គ្រប់គ្រងការខ្ចី និងសងសៀវភៅនៅក្នុងបណ្ណាល័យ ឬក្នុងថ្នាក់រៀន ដោយផ្អែកលើទម្រង់ដែលអ្នកបានផ្តល់ឱ្យ។

## លក្ខណៈពិសេស
- **បញ្ជីសៀវភៅ៖** កត់ត្រា និងគ្រប់គ្រងបញ្ជីសៀវភៅដែលមាន។
- **បញ្ជីអ្នកខ្ចី៖** កត់ត្រាឈ្មោះអ្នកខ្ចី និងស្ថានភាពខ្ចីសៀវភៅ។
- **តាមដានការខ្ចីសង៖** កត់ត្រាថ្ងៃខ្ចី និងថ្ងៃសង។

## សំណួរសម្រាប់ការធ្វើផែនការ

1. តើអ្នកចង់ឱ្យប្រព័ន្ធនេះគណនាពេលវេលាខ្ចីសងដោយស្វ័យប្រវត្តិដែរឬទេ?
   - ជម្រើស៖ (Recommended) បាទ/ចាស, ទេ

2. តើអ្នកត្រូវការមុខងារជូនដំណឹង (Notifications) នៅពេលដល់ថ្ងៃសងសៀវភៅដែរឬទេ?
   - ជម្រើស៖ (Recommended) បាទ/ចាស, ទេ

3. តើអ្នកចង់ឱ្យមានប្រព័ន្ធផ្ទៀងផ្ទាត់អ្នកខ្ចី (Login) ដែរឬទេ?
   - ជម្រើស៖ (Recommended) បាទ/ចាស, ទេ
